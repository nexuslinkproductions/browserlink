1. Modal (remove / recreate)

Open mounts #modal-root with #modal-target and #modal-close. Close removes it from the DOM; reopening recreates it identically.

2. Conditional section (remove / recreate)

Check mounts #cond-section with #cond-target. Uncheck removes it from the DOM; rechecking recreates it.

3. SPA views (pushState swap)

Buttons push history state and swap the subtree in #spa-view. View B mounts #spa-target; view A removes it from the DOM.

4. Same-origin iframe (remove / re-add)

srcdoc iframe (same origin as parent) contains #frame-target. Remove deletes the iframe; Re-add recreates it identically.
