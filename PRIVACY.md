# Privacy Policy

Effective date: 2026-08-10

Browserlink is a local-first browser annotation tool. This policy describes
what the software does with data.

## What browserlink is

Browserlink is an open-source Chromium extension, a local hub, and an MCP
server. You draw on web pages, pick elements, and send annotated context
(screenshots, element descriptors, instructions) to an AI harness of your
choice.

## Data handling

- **Local by default.** Annotations, screenshots, and element data are stored
  on your own machine in a local data directory. Nothing is uploaded to a
  server operated by the project.
- **Your browser stays yours.** The extension does not read your passwords,
  cookies, or session data. It only reads the page content you choose to
  annotate.
- **Delivery is explicit.** An annotation is sent to an AI harness only when
  you press Send. The destination is the session you select in the extension
  popup or configure in the hub.
- **No telemetry.** The project collects no usage analytics, no crash
  reports, and no personal data.

## Third-party services

When you send an annotation, it is delivered to the AI harness you have
configured (for example, a local Hermes instance or an MCP-capable client).
That service's own privacy policy applies to the data you send it. Browserlink
itself does not operate any cloud service.

## Open source

The full source code is published under the MIT License at
https://github.com/nexuslinkproductions/browserlink. Anyone can audit what
the software does.
